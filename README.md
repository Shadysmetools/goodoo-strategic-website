# Goodoo.ai Strategic Website

A comprehensive web application showcasing Goodoo.ai's strategic framework, product roadmap, and go-to-market strategy.

## Project Structure

This project contains separate components for each strategic document:

### 📋 Strategic Documents
- **Product Roadmap** - 12-month strategic plan with quarterly phases
- **GTM Strategy** - Go-to-market strategy for Odoo PMs
- **Master Plan** - 1-year CPO strategy with KPIs
- **User Personas** - Detailed customer profiles
- **Development Roadmap** - Technical implementation phases
- **Final Vision** - Complete product overview

### 🏗️ Architecture
- **Frontend**: Modern React/Next.js application
- **Styling**: Tailwind CSS for responsive design
- **Components**: Modular architecture for easy maintenance
- **Data**: JSON-based content management

## Branches
- `main` - Production-ready code
- `stage` - Staging environment for testing
- `test` - Development and feature testing

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)

## Development Workflow

1. Create feature branch from `test`
2. Develop and test features
3. Merge to `stage` for integration testing
4. Merge to `main` for production deployment
