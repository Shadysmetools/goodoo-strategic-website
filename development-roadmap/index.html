Goodoo AI Complete Development Roadmap & User Stories

Comprehensive MVP Development Strategy Across Three Strategic Phases

Executive Summary

  • Phase 1: Foundation: Core SaaS platform with basic meeting capture and AI interaction capabilities (Deadline: June 30, 2025)
  • Phase 2: Enhancement: Advanced transcription, bot features, and complete UI implementation (Deadline: July 15, 2025)
  • Phase 3: Monetization: Full intelligence hub with monetization, sharing, and project management (Deadline: August 15, 2025)

Phases

Phase 1: Core SaaS & Meeting Capture (Deadline: June 30, 2025)

Sprint: Sprint 1.2: Initial SaaS Offering
Features:
  • Prompting per Meeting: Implement AI prompting and response based on single meeting context
  • Mass Upload: Bulk upload multiple source documents to project
User Stories:
  • As a Project Manager, I want to ask AI questions about a specific meeting so that I can get contextual answers
  • As a Project Manager, I want to upload multiple documents at once so that I can quickly add sources to my project

Phase 2: Transcription & Bot Enhancements (Deadline: July 15, 2025)

User Stories:
  • As a Project Manager, I want fast transcription so that I can quickly access meeting content
  • As a Project Manager, I want to invite the bot to impromptu meetings so that I don't lose important discussions
  • As a Project Manager, I want a beautiful, intuitive interface so that I can easily navigate the platform
Sprints:
  • Sprint 1.3 - Performance - Semi-instant meeting transcription using bot
  • Sprint 1.5 - Invite Bot to Ad-Hoc Meetings - Invite Goodoo Bot to unscheduled meetings
  • Sprint 1.6 - UI Design - Full UI design for all customer-facing pages
Removed Feature: AI Renaming feature removed from scope

Phase 3: Monetization & Full Intelligence Hub (Deadline: August 15, 2025)

User Stories:
  • As a Project Manager, I want to pay for premium features so that I can access advanced functionality
  • As a Project Manager, I want to share conversations privately so that I can collaborate with my team
  • As a Project Manager, I want to preview HTML artifacts so that I can see the generated content before sharing
  • As a Project Manager, I want to manage my video library so that I can organize and access recordings easily
  • As a Project Manager, I want to chat with my entire project so that I can get answers from all sources
  • As a Project Manager, I want to control artifact privacy so that I can share appropriately with different audiences
  • As a Project Manager, I want to add audio and video sources so that I can include all types of content
  • As a Project Manager, I want to link to specific sources so that I can reference exact moments in conversations
Sprints:
  • Sprint 1.7 - Stripe Payment Integration - Handle user subscriptions and payments
  • Sprint 1.8 - Private Sharing - Share specific chat conversations privately
  • Sprint 1.8 - HTML Artifact Preview - Preview generated HTML code artifacts
  • Sprint 1.9 - Video Database & UI - Backend database and Video Page UI
  • Sprint 2.0 - Project Intelligence Hub

Development Timeline

  • Phase 1: Sprint 1.2 - Prompting per Meeting, Mass Upload (Deadline: June 30, 2025)
  • Phase 2: Sprint 1.3-1.6 - Performance, Ad-Hoc Bot, UI Design (Deadline: July 15, 2025)
  • Phase 3: Sprint 1.7-2.0 - Stripe Integration, Sharing, Intelligence Hub (Deadline: August 15, 2025)

Sprint Breakdown

Sprint 1.5: Core Google Meet Flow & Transcript Engine

Goals:
  • Establish meeting recording pipeline for Google Meet
  • Implement real-time transcription (2–3 minute chunks)
  • Assign video to project
Scope:
  • Chrome Extension (manual/auto Google Meet join)
  • Goodoo Bot joins and records screen/audio
  • Video Page with playback + live transcript chunks
  • Assign to existing/new project from Video Page
  • Project Page initializes with video page
  • Prompting per video
  • Hyperlink per video in the chat page
  • Bulk upload
Deliverables:
  • End-to-end: Record Meet > transcribe > video page > assign project
  • Transcript viewer with navigation and speaker ID

Sprint 2: Project Intelligence, Sources & UI

Goals:
  • Enable source-level AI interaction and advanced project tools
  • Improve project page as content hub
  • UI cohesion across Home, Project, and Video pages
Scope:
  • Source selection widget (upload, organize, tag)
  • AI contextual chat (Gemini-style) based on selected sources
  • Canvas panel with transcript + summary + action items
  • Public sharing of projects (view-only link)
  • Home Page project tiles and navigation polish
Deliverables:
  • Add source to project + AI chat answers with citations
  • Canvas output: summary, actions, transcript
  • Public share link per project
  • Final UI enhancements for MVP pages
